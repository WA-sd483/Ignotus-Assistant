# IgnotusAssistant（爱丽丝桌宠）

Windows 桌面语音助手 + Q 版桌宠：**听得懂你说话 → 思考 → 用角色声线念给你听 → 帮你操作电脑**。
唤醒、识别、语音合成都跑在**本机**，只有聊天内容会发给你自己配置的 API。

> 本项目源码公开**仅供查看与个人学习交流**，详见 [LICENSE](./LICENSE)。**请勿用于商业用途、请勿二次分发。**

## 主要功能

- **唤醒对话**：喊角色名即唤醒（唤醒词可自定义、多角色各喊各的），本地离线识别（sherpa-onnx / SenseVoice，中文），说完就提问。
- **接入 API 聊天**：默认 DeepSeek，兼容任意 OpenAI 兼容接口；可添加多个 API（接口地址 + 模型名）下拉切换，角色人设扮演，流式回复。
- **语音克隆（TTS）**：接本机 GPT-SoVITS 做零样本音色克隆，用角色声线把回复念出来（界面只显示中文）。
- **打开文件 / 软件 / 网页**：「打开 XXX」——网页 / 本地文件 / 文件夹 / 软件（含从磁盘添加的软件，可开「免 UAC 启动」）；收藏夹匹配，找不到就联网搜索兜底。
- **系统操作**：关机 / 重启 / 注销 / 锁屏；还可以问时间、日期、位置、IP。
- **桌宠互动**：Q 版小人浮在桌面，多状态表情、待机 / 休眠；可拖动或锁定位置；单击抚摸、摸头（patpat）模式；主界面关着时回复直接冒在贴图旁边。
- **各种模式**：静音模式（只回文字、不出声）、patpat 模式、节能模式、桌宠固定、开机自启。
- **安全边界**：可操作目录 / 可启动软件 / 可操作类型三张白名单，**默认全空** —— 加进来才允许；关机这类危险操作延迟执行，期间可以语音撤销。

## ⚠️ 这个仓库里**没有**素材与模型

贴图、音效、参考音频、ASR 模型都是大文件或第三方素材，**只放在 [Releases](../../releases) 的成品包里**，不进仓库：

| 仓库里有 | 仓库里没有（在 Releases 成品包里） |
|---|---|
| `app/`（全部源码）· `tests/`（回归测试）· `tools/`（开发脚本）· `persona/`（人设卡）· `assets/avatar/` `assets/icon/`（界面图）· `run.py` · `启动.bat` · `requirements.txt` | `pet/`（贴图帧）· `voices/`（音效 / 音频样本）· `refs/`（参考音频）· `models/`（ASR 模型 229 MB）· `_internal/` 与 `IgnotusAssistant.exe` |

**想直接跑起来（推荐）**：去 [Releases](../../releases) 下载成品 zip，解压后双击 `IgnotusAssistant.exe`（自带 Python 运行时，机器上不用装 Python）。

**只想从源码跑**：把成品包里的 `pet/ voices/ refs/ models/ assets/` 拷到本项目对应位置，然后：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe run.py
```

语音合成还需要本机的 **GPT-SoVITS** 安装（程序会自动探测 `D:\GPT-SoVITS`，也可以在「设置 → 语音模型 → 安装位置」里指定；不装也能用，只是不出声）。

## 第一次使用要自己做的两件事

1. **填 API key**：顶部「设置」→「API 管理」→ 填 DeepSeek API key（默认端点 `https://api.deepseek.com`）。key 只存在本机的 `config.json` 里，**不会上传、也不进仓库**（见 `.gitignore`）。
2. **添加可操作目录**：设置 →「权限管理」→「可操作目录/文件夹」→ 添加目录。**默认白名单是空的** —— 没添加之前「打开文件 / 查看目录」一律被拒（不是 bug，是设计）。

## 目录结构

```
app/          主程序（GUI / 桌宠 / 语音管线 / 权限 / 工具）
  ├─ main.py      入口与全局编排
  ├─ gui.py       主界面与设置/管理面板
  ├─ pet.py       桌宠窗口（状态机 / 气泡 / 摸头 / 右键菜单）
  ├─ tts.py       GPT-SoVITS 语音合成
  ├─ asr.py       本地语音识别
  ├─ tools.py     电脑操作（打开/搜索/关机…）与三级权限
  └─ config.py    配置读写
tests/        回归测试（离屏运行，不联网、不写真实配置）
tools/        开发辅助脚本
persona/      角色人设卡（.md）
assets/       界面图标与头像
run.py        源码形态入口
启动.bat      源码形态一键启动（用 .venv）
```
